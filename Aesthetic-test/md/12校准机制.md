# 12 校准机制

Version 2.0

---

# 1. 设计目标

数学公式并不是固定不变。

所有参数允许：

持续校准。

---

# 2. 数据集

建立：

HarmonyOS Card Dataset。

例如：

```

1000

张卡片

```

由：

UI设计师。

人工评分。

得到：

Gold Score。

---

# 3. 系统评分

系统：

自动评分。

得到：

Predict Score。

---

# 4. 误差计算

定义：

平均绝对误差：

```
MAE

=

Σ

|Predict-Gold|

/

N
```

同时计算：

均方根误差：

```
RMSE

=

√

Σ

(Predict-Gold)^2

/

N
```

用于评价：

系统是否接近人工评分。

---

# 5. 参数优化

根据：

MAE。

调整：

Gaussian：

Sigma。

Weight。

Ideal。

直到：

MAE最小。

---

# 6. 校准原则

校准：

只能调整：

参数。

不得：

修改公式。

保证：

系统长期稳定。

---

# 7. 最终目标

系统评分：

与设计师评分：

Pearson相关系数：

```

r > 0.90

```

MAE：

```

<5分

```

说明：

系统评分具有较高可信度。
